Sources & Methodology

How pseudosec. collects and presents information — and what you should know before relying on it.

!

Educational use only. pseudosec. is an independently run awareness project. It is not affiliated with the Australian Government, ACSC, or any security vendor. It is not a real-time security operations tool and should not be used as a substitute for professional security advice or official government guidance.

What pseudosec. is

pseudosec. aggregates publicly available Australian cyber security information into a single, readable view. It is designed for general awareness — helping everyday Australians and those new to cyber security understand the threat landscape without needing to monitor multiple government and industry sources themselves.

It is a personal project. There is no team, no 24/7 monitoring, and no service level agreement. Feeds may experience delays. Summaries may contain errors. Content is curated with care but is not professionally fact-checked before publication.

Data sources

Everything comes from publicly available sources. No proprietary threat intelligence feeds are used. The full feed list lives in fetch_cyber_news.py.

ASD’s ACSC — Alerts & Advisories
Australia’s national cyber security authority. Every ACSC alert and advisory is included, and these are the only items on the site that carry a threat level (see below). The most recent ACSC alert from the last 14 days, Critical or High first, is shown in the dashboard’s Official alert panel. cyber.gov.au often can’t be reached from GitHub’s servers; when that happens, ACSC items are found through Google News instead, which doesn’t carry ACSC’s severity, so they’re labelled ACSC without a level.
Each run RSS
Scamwatch (ACCC)
Scamwatch news and alerts, found through a Google News search limited to scamwatch.gov.au. Feeds the Scam to know panel on the dashboard. Headlines are shown as published.
Each run Google News RSS
Security news
Direct RSS feeds from Australian Cyber Security Magazine, Security Brief Australia, iTnews, Troy Hunt, Krebs on Security, Risky Business, Dark Reading and 404 Media, plus Google News searches limited to The Guardian, ABC, BleepingComputer and The Register. Articles are kept only if they match a topic. Coverage of the same event by several outlets is grouped into one story (see below), and stories are sorted by their latest coverage. News Corp, Nine and Seven West Media outlets and known clickbait sites are excluded.
Each run RSS
CISA Known Exploited Vulnerabilities (KEV)
The 10 most recently added entries in CISA’s catalog of vulnerabilities confirmed to be exploited in real attacks. KEV has no severity score, so none is shown; the panel shows whether a vulnerability is known to be used in ransomware and CISA’s fix-by date (the deadline CISA sets for US federal agencies).
Each run JSON
ASD Annual Cyber Threat Report
Source of the tracker rate, the statistics under it and the crime-type chart — always the most recent report, named on the dashboard. A scheduled check watches for each new report so the figures can be updated when it is published.
Annual Manual
Product update feeds
Official release feeds for Google Workspace, Chrome, Microsoft 365 and Claude Code, plus Google News searches for ChatGPT, Canva and Claude news. Shown in the Tool updates panel.
Each run RSS

Feeds are fetched by a scheduled GitHub Action: every 30 minutes on weekdays, 8am–6:30pm Sydney time, and every 8 hours on weekends. GitHub runs schedules on a best-effort basis, so gaps can be longer. The time of the last successful update is shown in the header and footer of the dashboard.

How the tracker number works

The large number on the dashboard is a projection, not a count. It takes the number of cybercrime reports ASD received in the year covered by its most recent Annual Cyber Threat Report and applies that same rate from 1 July of the current financial year. It resets each 1 July, and the rate changes when ASD publishes a new report.

! It is not a live feed of actual reports. It assumes this year tracks the last reported year exactly. ASD also notes that most cybercrime is never reported at all.
i The figures underneath it (incidents responded to, average costs, hotline calls, domains blocked) and the crime-type chart are final figures from that report, not projections. The dashboard names the report and financial year they come from.

How stories are chosen and labelled

i One entry per story. When different outlets report the same news, it’s shown once, led by the most reputable outlet (official sources first), with the others listed underneath. Follow-ups that add something new stay separate, and one outlet’s articles are never merged together. An AI model (Claude Haiku, by Anthropic) is shown the week’s headlines and first sentences and asked only which ones are the same news; it writes nothing that appears on the site, its answer is checked before use, and spending is capped at US$3 a month. Without it, a strict headline match is used instead.
i Threat levels (Critical, High, Advisory) appear only on ACSC items and come straight from the ACSC’s own alert titles. Other articles have no threat level: guessing severity from headline words proved unreliable.
! Topic tags (Scams, Compliance, AI & Tools and so on) are assigned automatically by keyword matching and are occasionally wrong. Apart from grouping coverage, no AI is used: every word on the site comes from the original sources or was written by hand.

Limitations

— This is a single-person project. There is no team monitoring feeds or responding to incidents around the clock.
— Feed ingestion relies on external RSS sources and APIs. Delays, outages, or changes to upstream sources may result in stale or missing data.
— pseudosec. does not generate original threat intelligence. All content is drawn from publicly available sources. It is a synthesis and presentation layer, not an intelligence product.
— For specific cyber security advice, contact a qualified security professional, the Australian Signals Directorate, or call the ACSC hotline on 1300 CYBER1.
